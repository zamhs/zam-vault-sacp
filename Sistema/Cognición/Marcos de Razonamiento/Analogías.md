# Analogías

## Qué es
Transferir la estructura de relaciones de un dominio conocido a un dominio nuevo, marcando explícitamente en qué punto la analogía deja de ser válida.

## Cuándo usarlo
Cuando el problema nuevo comparte una estructura relacional (no solo apariencia superficial) con un problema ya entendido en otro dominio, y esa estructura puede iluminar posibles soluciones o riesgos.

## Cómo aplicarlo
1. Identifica el dominio fuente (conocido) y el dominio destino (nuevo) del problema.
2. Especifica qué elementos de la estructura se corresponden entre ambos (no solo el parecido superficial, sino la relación funcional).
3. Transfiere las implicaciones de la estructura fuente al dominio destino como hipótesis a validar.
4. Marca explícitamente los puntos donde el dominio destino se diferencia del dominio fuente y la analogía deja de sostenerse.
5. Usa la analogía como punto de partida, no como prueba: valida las conclusiones transferidas con evidencia propia del dominio destino.

## Riesgos de mal uso
Extender la analogía más allá de donde la estructura realmente es compartida, tratando parecidos superficiales como si fueran equivalencias estructurales.

# Pensamiento Causal

## Qué es
Identificar relaciones de causa-efecto entre variables, distinguiéndolas de simples correlaciones o coincidencias temporales.

## Cuándo usarlo
Cuando el problema exige explicar *por qué* ocurrió algo (no solo describir *qué* ocurrió) o predecir el efecto de una intervención futura sobre una variable.

## Cómo aplicarlo
1. Enumera las variables involucradas y su orden temporal (la causa precede al efecto).
2. Pregunta si existe un mecanismo plausible que conecte la causa propuesta con el efecto observado, no solo una asociación estadística.
3. Busca variables de confusión: ¿hay una tercera variable que explique ambas?
4. Considera si la causalidad es multicausal: rara vez un efecto tiene una única causa suficiente.
5. Si es posible, busca evidencia de manipulación (experimento, cuasi-experimento, o al menos variación natural) que respalde la dirección causal propuesta.

## Riesgos de mal uso
Confundir correlación con causalidad, o fijarse en una única causa "cómoda" cuando el fenómeno responde a múltiples factores interactuantes.

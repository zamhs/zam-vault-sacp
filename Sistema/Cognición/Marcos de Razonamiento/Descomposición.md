# Descomposición

## Qué es
Dividir un problema complejo en partes más pequeñas y manejables que puedan abordarse por separado.

## Cuándo usarlo
Cuando un problema es demasiado grande o ambiguo para abordarlo de una vez, y separarlo en componentes permite avanzar en paralelo o con mayor claridad sobre cada parte.

## Cómo aplicarlo
1. Define el problema completo con la mayor precisión posible antes de dividirlo.
2. Identifica sub-problemas o componentes que puedan resolverse de forma relativamente independiente.
3. Verifica que la división sea exhaustiva (cubre todo el problema original) y sin solapamientos innecesarios.
4. Resuelve o investiga cada parte por separado.
5. Recompón las soluciones parciales en una respuesta integrada al problema original, revisando que encajen entre sí.

## Riesgos de mal uso
Perder de vista las interacciones entre las partes al descomponer, tratando componentes que en realidad están fuertemente acoplados como si fueran independientes (ver Pensamiento Sistémico como complemento necesario).

# Modelado

## Qué es
Construir una representación simplificada pero útil de un fenómeno, que permita razonar, predecir o decidir sin necesidad de capturar toda su complejidad real.

## Cuándo usarlo
Cuando el fenómeno es demasiado complejo para razonar directamente sobre él, y una versión simplificada con las variables clave permite obtener predicciones o decisiones suficientemente buenas.

## Cómo aplicarlo
1. Define el propósito del modelo: ¿qué pregunta específica debe responder? (un modelo sin propósito claro no tiene criterio de simplificación).
2. Selecciona las variables y relaciones que son relevantes para ese propósito, y descarta explícitamente las que no lo son.
3. Construye la representación simplificada (esquema, ecuación, escenario, diagrama) con esas variables.
4. Usa el modelo para generar predicciones o decisiones, verificando que sean consistentes con lo que ya se sabe del fenómeno real.
5. Revisa el modelo cuando aparezca evidencia que no encaje con sus predicciones, ajustándolo o reconociendo sus límites.

## Riesgos de mal uso
Confundir el modelo con la realidad; un modelo útil para un propósito no es lo mismo que un modelo verdadero en todos sus detalles, y tratarlo como tal lleva a conclusiones erróneas fuera de su ámbito de validez.

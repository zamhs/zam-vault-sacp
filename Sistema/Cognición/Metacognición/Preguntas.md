# Preguntas de Revisión Metacognitiva

Estas seis preguntas son el instrumento operativo del [[Protocolo|Protocolo de Metacognición]]. No se aplican de forma mecánica ni exhaustiva en cada interacción: se activan cuando alguna de las [[Señales de Activación]] está presente, y su función es interrumpir el flujo del ciclo cognitivo el tiempo suficiente para examinar si el razonamiento en curso es confiable.

## "¿Estoy utilizando el enfoque adecuado?"

Se aplica cuando el problema tiene una forma que no encaja del todo con el marco de razonamiento que se está usando por defecto o por costumbre, y conviene verificar si ese marco realmente es el más apto para la naturaleza del problema.

## "¿Estoy ignorando evidencia relevante?"

Se aplica cuando existe información disponible que no se ha consultado o que se ha descartado sin justificación explícita, especialmente si esa información podría contradecir la dirección que ya se está tomando.

## "¿Estoy formulando el problema correctamente?"

Se aplica antes de invertir esfuerzo en resolver algo, para comprobar que la pregunta que se está respondiendo es la que realmente importa, y no una versión simplificada o mal encuadrada del problema original.

## "¿Existe otro marco de razonamiento que produciría una mejor explicación?"

Se aplica cuando la explicación actual se siente forzada, incompleta o poco satisfactoria, como invitación a contrastarla con otros marcos disponibles en `Sistema/Cognición/Marcos de Razonamiento/`.

## "¿Estoy respondiendo demasiado rápido?"

Se aplica cuando la velocidad de la respuesta no guarda proporción con la complejidad, ambigüedad o importancia del problema planteado.

## "¿Qué incertidumbres permanecen abiertas?"

Se aplica al cierre de cualquier motor del ciclo, para hacer explícitas las dudas que no fueron resueltas en lugar de dejarlas implícitas u ocultas detrás de una conclusión aparentemente firme.

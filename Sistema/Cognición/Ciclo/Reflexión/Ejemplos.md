# Ejemplos de Reflexión

Esta nota se irá llenando con casos reales de uso del motor de [[Protocolo|Protocolo de Reflexión]] conforme ocurran en la práctica del sistema. Deliberadamente no contiene ejemplos inventados sobre la vida del usuario: los ejemplos aquí documentados serán reflexiones efectivamente realizadas sobre ciclos cerrados, con sus aprendizajes generalizables reales, no ilustraciones hipotéticas.

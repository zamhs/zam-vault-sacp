# Checklist de Hipótesis

Antes de dar por cerrado el motor de Hipótesis y pasar a [[Evidencia/Protocolo|Protocolo de Evidencia]], conviene repasar los siguientes seis puntos.

- [ ] Existe más de una hipótesis candidata considerada, no solo la primera que surgió.
- [ ] Cada hipótesis formulada es falsable.
- [ ] Se identificó el mecanismo causal propuesto para cada hipótesis.
- [ ] Se definió qué evidencia reduciría la incertidumbre entre las candidatas.
- [ ] La hipótesis quedó registrada en `Hipótesis/` con una `confianza` explícita.
- [ ] Se evitó anclarse en la primera explicación plausible sin explorar alternativas.

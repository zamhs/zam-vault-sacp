# Checklist de Actualización del Conocimiento

Antes de dar por cerrado el motor de Actualización del Conocimiento y retroalimentar al motor de [[Investigación/Protocolo|Protocolo de Investigación]], conviene repasar los siguientes seis puntos.

- [ ] Se identificaron todas las piezas de conocimiento afectadas por el ciclo (Conceptos, Patrones, Hipótesis, Modelos).
- [ ] Se aplicaron las reglas de promoción de Hipótesis a Modelo, si correspondía.
- [ ] Se documentaron las contradicciones nuevas, si las hubo.
- [ ] Se actualizó el Modelo del Usuario cuando fue pertinente.
- [ ] Toda nota nueva pasó el criterio de admisión a la memoria.
- [ ] Quedó registrada la pregunta o laguna que retroalimenta al motor de Investigación.

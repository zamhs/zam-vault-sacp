# MOC - Hipótesis

Esta carpeta (`/Hipótesis/`) contiene explicaciones propuestas y falsables de patrones observados — el cuarto peldaño de la escalera epistemológica (ver [[Epistemología del Sistema]] §3). Cuando una hipótesis acumula suficiente evidencia convergente y `confianza: alta` sostenida, puede promoverse a un Modelo (ver [[Epistemología del Sistema]] §4).

Usa `Sistema/Plantillas/Plantilla - Hipótesis.md` para crear notas nuevas.

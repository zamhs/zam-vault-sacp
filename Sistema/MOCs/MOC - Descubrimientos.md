# MOC - Descubrimientos

Esta carpeta (`/Descubrimientos/`) contiene hallazgos inesperados o significativos que no encajan limpiamente en el flujo lineal dato → concepto → patrón → hipótesis → modelo. Un Descubrimiento puede surgir de una Conversación, una Investigación, o directamente poner en duda un Modelo existente (ver [[Epistemología del Sistema]] §5).

Usa `Sistema/Plantillas/Plantilla - Descubrimiento.md` para crear notas nuevas.

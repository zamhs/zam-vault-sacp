# MOC - Conceptos

Esta carpeta (`/Conceptos/`) contiene conocimiento de Nivel 1: ideas o definiciones estables, suficientemente claras para nombrarse y reutilizarse en otras notas. Es el segundo peldaño de la escalera epistemológica (dato → **concepto** → patrón → hipótesis → modelo, ver [[Epistemología del Sistema]] §3).

Cada Concepto nuevo debe pasar el criterio de admisión a la memoria (ver [[Convenciones del vault]] §4) y usar `Sistema/Plantillas/Plantilla - Concepto.md`.

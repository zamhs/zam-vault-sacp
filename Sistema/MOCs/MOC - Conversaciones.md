# MOC - Conversaciones

Esta carpeta (`/Conversaciones/`) contiene el registro de conversaciones relevantes entre el usuario y la IA (o con otras personas) que produjeron conocimiento digno de conservarse. Una Conversación puede producir un Descubrimiento o disparar el motor de Investigación (ver [[Arquitectura Cognitiva del Sistema]] §6).

Usa `Sistema/Plantillas/Plantilla - Conversación.md` para crear notas nuevas.

## Listado (activable con Dataview)

```text
FROM "Conversaciones"
SORT fecha DESC
```

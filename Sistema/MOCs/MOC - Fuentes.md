# MOC - Fuentes

Esta carpeta (`/Fuentes/`) contiene el registro de fuentes primarias y secundarias usadas por el sistema — libros, artículos, conversaciones externas, datos. La calidad de una fuente (primaria vs. secundaria, replicada vs. anecdótica) determina su peso como evidencia (ver [[Epistemología del Sistema]] §2).

Usa `Sistema/Plantillas/Plantilla - Fuente.md` para crear notas nuevas.

## Listado (activable con Dataview)

```text
FROM "Fuentes"
SORT fecha_creacion DESC
```

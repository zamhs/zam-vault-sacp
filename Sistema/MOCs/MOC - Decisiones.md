# MOC - Decisiones

Esta carpeta (`/Decisiones/`) contiene notas atómicas de Nivel 1 sobre decisiones reales tomadas por el usuario. Es distinta del motor/metodología "Decisiones" que vive en `Sistema/Cognición/Ciclo/Decisiones/` — ese motor es el protocolo que produce las notas que aquí se archivan.

`Modelo del Usuario/Historial de Decisiones/Síntesis.md` enlaza aquí en vez de duplicar contenido (ver [[Convenciones del vault]] §6).

Usa `Sistema/Plantillas/Plantilla - Decisión.md` para crear notas nuevas.

## Listado (activable con Dataview)

```text
FROM "Decisiones"
SORT fecha_creacion DESC
```

# MOC - Patrones

Esta carpeta (`/Patrones/`) contiene regularidades observadas entre conceptos o datos a lo largo del tiempo o de varios casos — el tercer peldaño de la escalera epistemológica (ver [[Epistemología del Sistema]] §3). Un Patrón puede disparar una nueva Hipótesis que lo explique.

Usa `Sistema/Plantillas/Plantilla - Patrón.md` para crear notas nuevas.

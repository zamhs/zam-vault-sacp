# MOC - Modelo del Usuario

`Modelo del Usuario/` es un modelo computacional **dinámico** del usuario, no una biografía estática. Cada nota lleva `confianza` y `evidencia_base`, y se actualiza conforme el sistema acumula evidencia real sobre cómo piensa, decide y evoluciona el usuario (ver [[Arquitectura Cognitiva del Sistema]] §3).

Ninguna de las 19 subcarpetas contiene datos inventados: todas empiezan como índices vacíos, `confianza: baja`, pendientes de completarse con evidencia real.

## Las 19 subcarpetas

| Categoría | Contenido |
|---|---|
| [[Índice - Identidad]] | Quién es el usuario, roles que ocupa |
| [[Índice - Objetivos]] | Metas de corto, mediano y largo plazo |
| [[Índice - Valores]] | Principios que guían las prioridades |
| [[Índice - Principios]] | Reglas de conducta personales consistentes |
| [[Índice - Preferencias]] | Gustos y formas preferidas de trabajar/decidir |
| [[Índice - Estilo Cognitivo]] | Cómo procesa información y aprende |
| [[Índice - Modelos Mentales]] | Marcos/analogías habituales del usuario |
| [[Índice - Fortalezas]] | Capacidades donde destaca consistentemente |
| [[Índice - Limitaciones]] | Restricciones reales (tiempo, conocimiento, recursos) |
| [[Índice - Puntos Ciegos]] | Áreas donde sistemáticamente no ve algo relevante |
| [[Índice - Sesgos Detectados]] | Sesgos cognitivos observados en su razonamiento |
| [[Índice - Conocimiento Actual]] | Dominios que conoce bien hoy |
| [[Índice - Habilidades]] | Capacidades técnicas o prácticas desarrolladas |
| [[Síntesis]] (Proyectos Activos) | Enlaza `/Proyectos/` — no duplica |
| [[Índice - Intereses]] | Temas que atraen su curiosidad |
| [[Síntesis]] (Historial de Decisiones) | Enlaza `/Decisiones/` — no duplica |
| [[Índice - Aprendizaje]] | Qué está aprendiendo actualmente y cómo |
| [[Índice - Evolución]] | Cómo ha cambiado a lo largo del tiempo |
| [[Índice - Estado Actual]] | Instantánea del momento presente |

Nota: `Proyectos Activos` e `Historial de Decisiones` no crean notas propias — duplicarían `/Proyectos/` y `/Decisiones/`. Cada una recibe únicamente `Síntesis.md`, que enlaza vía `relacionado_con` (ver [[Convenciones del vault]] §6).

# Ingeniería de Software

## Objetivo

Desarrollar las habilidades técnicas necesarias para convertirse en un ingeniero de software altamente competente, con énfasis en arquitectura, desarrollo de aplicaciones, diseño de sistemas e inteligencia artificial.

## Contexto

Marcada con `alcance: area_continua` (no `proyecto` en sentido estricto) porque, a diferencia del SACP, no tiene un hito final claro — es una responsabilidad de desarrollo permanente. Base actual: ecosistema JavaScript y React Native, desarrollo móvil multiplataforma. Áreas de profundización declaradas: arquitectura de software, diseño de sistemas escalables, patrones de diseño, bases de datos, sistemas distribuidos, buenas prácticas de ingeniería. Recorrido previo por ciberseguridad, desarrollo móvil, Flutter, React y React Native antes de asentarse en su enfoque actual.

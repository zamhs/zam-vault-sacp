# Desarrollo Intelectual

## Objetivo

Construir una comprensión profunda sobre inteligencia, aprendizaje, ciencias cognitivas, psicología, neurociencia, filosofía e inteligencia artificial, integrando estas disciplinas dentro de un modelo coherente.

## Contexto

Marcada con `alcance: area_continua` — es, junto con Ingeniería de Software e Inglés, una de las responsabilidades permanentes que Zam distingue explícitamente de proyectos con hito final como el SACP. Es el área que más se solapa conceptualmente con el propio SACP: ambos comparten el objetivo de comprender la inteligencia y el aprendizaje, pero esta área es la actividad continua de estudio, mientras el SACP es el sistema/producto que resulta de aplicarla.

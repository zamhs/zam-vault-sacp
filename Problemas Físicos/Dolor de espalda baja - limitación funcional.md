# Dolor de Espalda Baja — Limitación Funcional

## Descripción del problema

Zam reporta dolor de espalda baja recurrente que **interfiere directamente con la capacidad de completar tareas cotidianas**.

### Síntomas reportados (22 de julio de 2026):
- Dolor en región lumbar (espalda baja)
- Dificultad para agacharse
- Camina lentamente
- Reduce capacidad para realizar trabajo físico/doméstico
- **Impacto observable**: Intentó lavar ropa y acomodar cuarto, pero solo pudo completar parcialmente por el dolor

### Patrones observados:
- Problema intermitente (no es constante, pero aparece frecuentemente)
- No hay documentación clara de disparadores (¿postura prolongada? ¿sobre-entrenamiento? ¿técnica de levantamiento?)
- Interfiere con planes del día (tareas no completadas por limitación física)

## Conexión con estado actual (22 de julio)

Zam está experimentando simultáneamente:
1. **Sueño interrumpido** (noche del 21-22, se despertó a media noche)
2. **Cansancio cognitivo** (reportado 21 de julio)
3. **Performance física comprometida** (GYM quality 50/100 el 22, rutina incompleta por sueño)
4. **Ahora: dolor de espalda** que limita actividades básicas

### Hipótesis de patrón emergente:
Podría haber una cascada donde:
- Sueño pobre → fatiga → menor estabilidad muscular → dolor de espalda compensatorio
- O alternativa: técnica de ejercicio comprometida por fatiga → sobrecarga lumbar → dolor

No hay confirmación aún. Requiere observación más sistemática.

## Preguntas abiertas que necesitan verificación

1. **¿Cuándo empezó?** ¿Es reciente o crónico desde hace meses/años?
2. **¿Qué lo dispara?** ¿Postura prolongada? ¿Ejercicios específicos? ¿Posición para dormir?
3. **¿Ha buscado diagnóstico profesional?** ¿Fisioterapista? ¿Radiología?
4. **¿Qué intensidad tiene?** (1-10 escala de dolor)
5. **¿Aparece predeciblemente?** (después de ciertos ejercicios, días específicos, etc.)
6. **¿Hay algún movimiento que lo empeore o mejore?**

## Implicación para el SACP

Si el dolor de espalda es crónico o frecuente, necesita:
1. Diagnóstico y tratamiento (no es "algo que ignorar")
2. Incorporación en el modelo de capacidades físicas reales
3. Ajuste de objetivos de desarrollo físico (¿el programa de gym es compatible con esta limitación?)
4. Documentación en los logs diarios (¿cuándo aparece? ¿intensidad? ¿impacto en performance?)

## Acción sugerida (próximas 48 horas)

1. Recolectar datos: cada vez que aparezca el dolor, registrar:
   - Hora del día
   - Actividad que lo desencadenó (o si fue espontáneo)
   - Intensidad (1-10)
   - Duración
   - Qué movimientos empeoran/mejoran

2. Consideración profesional: Si persiste, evaluación por fisioterapista
